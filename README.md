# AntiMareo (Android nativo)

1. Crea un repositorio en GitHub y sube todo este contenido (incluida la carpeta .github).
2. Ve a la pestaña Actions, abre "Build APK" y espera a que termine (unos 3-5 minutos).
3. Descarga el artefacto "antimareo-apk", descomprime e instala app-debug.apk en el teléfono
   (permite instalar de orígenes desconocidos).
4. Abre la app: permiso 1 (mostrar sobre otras apps), permiso 2 (ubicación y notificaciones), Iniciar guías.
